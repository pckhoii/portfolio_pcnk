# Artifact System

Core artifacts share a transparent canvas, thin monoline strokes, restrained cyan/gold/violet accents, geometric construction, and no embedded animation.

- `signal-beacon.svg`: receiving and identifying a signal.
- `observatory.svg`: inspecting a question through a system.
- `mission-map.svg`: moving from question to route and decision.
- `flight-recorder.svg`: preserving a professional trace.
- `open-book.svg`: turning a reading artifact into an idea.
- `north-star.svg`: final orientation and direction.

The library also contains supporting artifacts for archive, contact, notes, and transitions. Reuse an artifact only when its narrative meaning applies; do not use it as a background decoration.
